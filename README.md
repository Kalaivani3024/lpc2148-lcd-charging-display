# LPC2148 LCD Charging Symbol Display System

## Overview

The **LPC2148 LCD Charging Symbol Display System** is an embedded systems project developed using **Embedded C**, **Keil uVision**, and **Proteus Professional**. The project demonstrates the interfacing of a **16x2 LCD** with the **LPC2148 ARM7 Microcontroller** to display a battery charging symbol continuously. It provides a simple example of LCD interfacing, GPIO programming, and embedded system design.

---

## Features

* Displays a battery charging symbol on a 16x2 LCD.
* Developed using Embedded C programming.
* Simulated using Proteus Professional.
* Program compiled using Keil uVision.
* Demonstrates LCD interfacing with LPC2148.
* Simple and beginner-friendly embedded systems project.

---

## Hardware Requirements

* LPC2148 ARM7 Microcontroller
* 16x2 LCD Display
* Power Supply (3.3V)
* Connecting Wires

---

## Software Requirements

* Keil uVision
* Proteus Professional 8
* Embedded C

---

## How to Run the Project

1. Open the Keil project (.uvproj).
2. Build the project to generate the HEX file.
3. Open the Proteus simulation (.pdsprj).
4. Load the generated HEX file into the LPC2148 microcontroller.
5. Run the simulation.
6. The LCD will continuously display the battery charging symbol.
